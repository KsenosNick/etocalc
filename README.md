# Электротехнический калькулятор

Настольное приложение для инженеров-электриков: расчёт падения напряжения
в кабельных линиях и управление справочником кабелей. Распространяется как
десктопное приложение (Electron) с отдельной серверной частью (Spring Boot).

## Возможности

- **Расчёт падения напряжения** (ΔU = k·I·L·(r·cosφ + x·sinφ)):
  - однофазные (2–3 провода) и трёхфазные (4–5 проводов) сети;
  - корректировка активного сопротивления по температуре окружающей среды;
  - учёт параллельных кабелей в пучке;
  - ввод нагрузки током (А) или мощностью (кВт) с автопересчётом;
  - оценка качества по отклонению конечного напряжения от целевого (220/380 В);
  - подробный ход расчёта с формулами и подстановками.
- **Справочник кабелей (CRUD)**: глобальный поиск, пагинация, серверная сортировка,
  создание, редактирование, одиночное и массовое удаление.
- **Экспорт/импорт справочника** в JSON с режимами SKIP / UPDATE / DUPLICATE.
- Тёмная и светлая тема оформления.

## Технологический стек

| Слой      | Технологии |
|-----------|------------|
| Бэкенд    | Java 17+, Spring Boot 3, Spring Data JPA, Flyway, H2 (по умолчанию) / PostgreSQL (профиль `postgres`) |
| Фронтенд  | Vue 3 + TypeScript, PrimeVue 4, Vite, Axios |
| Десктоп   | Electron, electron-builder (AppImage / deb / rpm, Windows portable) |

## Запуск в режиме разработки

1. Бэкенд: `./gradlew bootRun` (порт 8081, файловая БД H2 в `./data`).
2. Фронтенд: `cd frontend && npm install && npm run electron:dev`.

## Сборка релиза

1. Бэкенд: `./gradlew bootJar` → `build/libs/etocalc-*.jar`, запуск: `java -jar etocalc-*.jar`.
2. Фронтенд: `cd frontend && npm run electron:build -- --win portable`
   (для Linux: `--linux AppImage deb rpm`).
3. Распространяйте **парой**: исполняемый файл + jar. Приложение ожидает
   бэкенд по адресу `http://localhost:8081`.
